# Письмо для Марьям

Интерактивное цифровое любовное письмо. Next.js (App Router) + React, обычный JavaScript, CSS Modules и Framer Motion. Эта папка полностью самостоятельный проект: свой `package.json`, свои переменные окружения, свой деплой. Письмо для Сабины лежит в корне репозитория и никак с этим проектом не связано.

## Что происходит на сайте

1. **Код.** Экран «Для Марьям», подпись «У меня есть для тебя кое-что...» и поле ввода. Верный код: `Maryam` (регистр и пробелы по краям не важны, `Марьям` кириллицей тоже подходит). Неверный код: поле встряхивается и появляется «Кажется, это не тот код».
2. **Конверт.** После верного кода поле плавно исчезает, появляется кремовый конверт с золотой печатью-сердцем и подписью «Для Марьям».
3. **Открытие.** По нажатию на «Открыть письмо»: печать вздрагивает, клапан поднимается, из конверта выходит сложенный втрое лист, летит на своё место и разворачивается. Именно в этот момент (по нажатию, как требуют браузеры) начинает плавно звучать музыка.
4. **Письмо.** Заголовок «пишется», затем абзацы появляются один за другим. Следующий абзац начинает писаться, только когда предыдущий дописан и до него долистали, поэтому ничего не пишется там, где никто не смотрит. Предложение «Марьям, ты действительно очень много для меня значишь.» выделено, а последнее сердце бьётся. Нажатие на лист показывает весь текст сразу.
5. **Фон.** Тёплый свет, золотые частицы, лёгкие сердечки и немного бабочек. Дальние бабочки летают за листом, ближние перед ним и бледнеют над текстом, чтобы не мешать чтению.
6. **«Я прочитала».** Кнопка появляется под письмом, когда текст дописан.
7. **Финал.** Большое сердце поднимается из свечения, летят бабочки, золотые частицы и сердечки, лёгкое конфетти и несколько небольших фейерверков. Надпись «Для тебя, Марьям», под ней «Спасибо, что прочитала.» В это же время на почту уходит уведомление.

Текст письма и все надписи лежат в одном файле: `src/lib/content.js`.

В проекте нет символов emoji: все сердца нарисованы SVG (`src/components/Heart.js`), поэтому выглядят одинаково на любом устройстве.

## Запуск

```bash
cd maryam
npm install
npm run dev        # http://localhost:3000
```

Продакшн-сборка: `npm run build`, затем `npm start`.

Посмотреть на телефоне, пока сайт запущен на компьютере (одна Wi-Fi сеть): `DEV_ORIGINS=192.168.1.20 npm run dev` (подставьте IP компьютера) и откройте `http://192.168.1.20:3000`. Без `DEV_ORIGINS` режим разработки Next.js не отдаёт скрипты чужим адресам, и страница на телефоне не оживёт (в `npm start` такого ограничения нет).

## Музыка и звуки

- **Музыка.** Положите файл `public/music/music.mp3` (подробности в `public/music/README.txt`) и пересоберите сайт. Играет по кругу, тихо появляется за несколько секунд после нажатия «Открыть письмо». Подходит спокойный инструментальный трек; используйте музыку, на которую у вас есть права.
- **Если файла нет**, сайт сам играет очень тихую «музыкальную шкатулку», сочинённую на лету, чтобы страница не молчала случайно. Проверить, как она звучит именно у вас, нужно на слух: я не мог её послушать.
- **Звуки.** Печать, шелест бумаги, мягкий звон при появлении письма и переливы в финале синтезируются в браузере (файлы не нужны) и звучат тихо.
- **Кнопка звука** в правом верхнем углу появляется после первого нажатия и выключает всё. Когда вкладка не видна, звук приостанавливается.
- На iPhone звук не играет, если включён беззвучный режим переключателем сбоку.

## Уведомление на email (важно)

Когда нажимается «Я прочитала», браузер отправляет запрос на серверный маршрут `POST /api/finished`, а письмо отправляет уже сервер. Ключ почтового сервиса хранится только в переменных окружения на сервере и никогда не попадает в браузер (`src/app/api/finished/route.js`, `src/lib/mailer.js`). Письмо приходит с темой «Марьям открыла и прочитала письмо» и текстом «Она дошла до финала и нажала кнопку.»

По умолчанию используется [Resend](https://resend.com) (бесплатного тарифа достаточно), дополнительные пакеты не нужны.

1. Зарегистрируйтесь на https://resend.com **с адресом `nekruzhakimov320@gmail.com`**. Пока вы не подтвердили собственный домен, Resend разрешает отправлять письма только на адрес, на который зарегистрирован аккаунт.
2. В панели Resend откройте **API Keys**, создайте ключ (*Sending access*) и скопируйте его.
3. Добавьте переменные окружения:

   | Переменная | Значение | Обязательна |
   | --- | --- | --- |
   | `EMAIL_SERVICE_API_KEY` | ключ из Resend | да |
   | `EMAIL_TO` | `nekruzhakimov320@gmail.com` | нет (это значение по умолчанию) |
   | `EMAIL_FROM` | `Letter <onboarding@resend.dev>` | нет (значение по умолчанию) |
   | `EMAIL_TIMEZONE` | например `Asia/Dushanbe` | нет (по умолчанию `UTC`; часовой пояс времени внутри письма) |

   Локально: скопируйте `.env.example` в `.env.local` и заполните. На Vercel: *Project -> Settings -> Environment Variables*, затем **Redeploy**.
4. Пройдите письмо до конца и нажмите «Я прочитала». Если письма нет, смотрите логи сервера (ошибки начинаются с `[finished]`) и папку «Спам».

Что сделано для надёжности: сервер не принимает запросы с чужого сайта (проверка `Origin`); повторное нажатие в течение 30 секунд второго письма не отправляет; если в этот момент пропала сеть, запрос повторяется и при необходимости уходит при следующем открытии страницы; Марьям ничего не видит про почту.

Другой почтовый сервис: вся отправка находится в одной функции `sendFinishedNotification` в `src/lib/mailer.js`.

## Размещение

Папка `maryam` деплоится отдельно от письма для Сабины. На Vercel: *Add New -> Project*, выберите этот репозиторий и в поле **Root Directory** укажите `maryam`. Так у каждого письма свой адрес и свои переменные окружения, и по ссылке на одно письмо нельзя увидеть другое. Подойдёт и любой хостинг с Node.js (`npm run build && npm start` внутри папки). Статический экспорт не подойдёт: нужен серверный маршрут для почты.

Страница закрыта от поисковиков (`noindex`).

## Структура

```
src/
  app/
    layout.js              шрифты, метаданные, viewport
    page.js                находит public/music/music.mp3 при сборке
    globals.css            цвета, бумага, общие стили
    api/finished/route.js  серверный маршрут: принимает «Я прочитала» и отправляет письмо
  components/
    LetterExperience.js    управляет этапами: код -> конверт -> письмо -> финал, звук
    CodeGate.js            ввод кода
    EnvelopeScene.js       конверт: печать, клапан, лист выходит и разворачивается (3D на CSS)
    LoveLetter.js          лист с письмом, появление абзацев по очереди
    ReadAction.js          кнопка «Я прочитала»
    Finale.js              финальный экран
    SoundToggle.js         кнопка звука
    Atmosphere.js          фон: свет, частицы, сердечки
    Butterflies.js         бабочки (простая симуляция полёта)
    EffectsCanvas.js       canvas для конфетти и фейерверков (движок: src/lib/effects.js)
  lib/
    content.js             текст письма, код и все надписи
    audio.js               музыка и звуки (Web Audio)
    mailer.js              отправка письма (только сервер)
    notify.js              отправка «Я прочитала» с повторами (браузер)
```

## Телефоны и доступность

- Кнопки и поле крупные, для касания (от 54 px), шрифт поля не меньше 16 px, поэтому iPhone не увеличивает страницу при фокусе.
- Горизонтальной прокрутки нет; учитываются вырезы экрана (`safe-area`) и динамическая высота экрана на iPhone (`dvh`).
- Конверт подстраивается под высоту экрана, в том числе в альбомной ориентации.
- При включённой системной настройке «уменьшить движение»: конверт открывается простым появлением письма, текст появляется сразу, нет падающих частиц и фейерверков, остаются три бабочки и несколько медленных сердечек в финале.
