# Письмо для Саби

> В этом репозитории два самостоятельных письма. Это (корень) письмо для Сабины. Письмо для Марьям лежит в папке [`maryam/`](maryam/README.md): у него свой `package.json`, свои переменные окружения и свой деплой (на Vercel укажите Root Directory `maryam`).

Интерактивное цифровое письмо с просьбой о прощении. Next.js (App Router) + React, обычный JavaScript, CSS Modules и Framer Motion. Никаких тяжёлых библиотек: конфетти, фейерверки и бабочки нарисованы самим проектом.

## Что происходит на сайте

1. **Код.** Экран «Для Саби» и поле ввода. Верный код: `Sabina` (регистр и пробелы по краям не важны, `Сабина` кириллицей тоже подходит, чтобы не мучить телефонную клавиатуру). Неверный код: поле встряхивается и появляется «Попробуй ещё раз».
2. **Кнопка «Открыть».** Появляется после верного кода.
3. **Конверт.** Кремовый конверт с восковой печатью-сердцем и подписью «Для Саби». По нажатию на «Открыть письмо»: печать вздрагивает, клапан поднимается, из конверта выходит сложенный втрое лист, летит на своё место и разворачивается.
4. **Письмо.** Текст «пишется» слово за словом, как от руки (нажатие на лист показывает весь текст сразу). Вокруг мягкие частицы, сердечки, лучи света и бабочки. Дальние бабочки летают за листом, ближние перед ним и слегка бледнеют над текстом.
5. **Вопрос «Ты меня простишь?»** Появляется под письмом, когда текст дописан. Кнопка «Нет» убегает в случайное место, которое всегда внутри экрана (и на телефоне тоже), меняет размер и шепчет сообщения. Кнопка «Да» с каждой попыткой чуть растёт.
6. **Финал.** После «Да»: конфетти, фейерверки, сердечки, золотая пыль, бабочки кружат вокруг большого сердца, затем «Спасибо, Сабина» и две строки под ним. В это же время на почту уходит уведомление.

Все тексты лежат в одном файле: `src/lib/content.js`.

В проекте нигде нет символов emoji: все сердца нарисованы SVG (`src/components/Heart.js`), поэтому они выглядят одинаково на любом устройстве.

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
```

Продакшн-сборка:

```bash
npm run build
npm start
```

### Посмотреть на телефоне, пока сайт запущен на компьютере

Телефон и компьютер должны быть в одной Wi-Fi сети. Узнайте IP компьютера (например `192.168.1.20`) и запустите:

```bash
DEV_ORIGINS=192.168.1.20 npm run dev
```

Откройте на телефоне `http://192.168.1.20:3000`. Без `DEV_ORIGINS` режим разработки Next.js не отдаёт скрипты чужим адресам, и страница на телефоне не оживёт (в `npm start` такого ограничения нет).

## Уведомление на email (важно)

Когда нажимается «Да», браузер отправляет запрос на серверный маршрут `POST /api/forgiven`, а письмо отправляет уже сервер. Ключ почтового сервиса хранится только в переменных окружения на сервере и никогда не попадает во фронтенд (`src/app/api/forgiven/route.js`, `src/lib/mailer.js`).

По умолчанию используется [Resend](https://resend.com) (бесплатного тарифа достаточно). Дополнительные пакеты не нужны.

### Настройка за 5 минут

1. Зарегистрируйтесь на https://resend.com **с адресом `nekruzhakimov320@gmail.com`**. Это важно: пока вы не подтвердили собственный домен, Resend разрешает отправлять письма только на адрес, на который зарегистрирован аккаунт.
2. В панели Resend откройте **API Keys**, создайте ключ (права *Sending access*) и скопируйте его.
3. Добавьте переменные окружения:

   | Переменная | Значение | Обязательна |
   | --- | --- | --- |
   | `EMAIL_SERVICE_API_KEY` | ключ из Resend | да |
   | `EMAIL_TO` | `nekruzhakimov320@gmail.com` | нет (это значение по умолчанию) |
   | `EMAIL_FROM` | `Letter <onboarding@resend.dev>` | нет (значение по умолчанию; поменяйте после подтверждения своего домена) |
   | `EMAIL_TIMEZONE` | например `Asia/Dushanbe` | нет (по умолчанию `UTC`, это часовой пояс времени внутри письма) |

   - Локально: скопируйте `.env.example` в `.env.local` и заполните.
   - На Vercel: *Project -> Settings -> Environment Variables*, затем сделайте **Redeploy**.
4. Проверьте: откройте сайт, пройдите до конца и нажмите «Да». На почту придёт письмо «Сабина тебя простила» с текстом «Она нажала кнопку «Да» на странице с просьбой о прощении».

Если письма нет, посмотрите логи сервера: ошибки начинаются с `[forgiven]`. Письмо мог отфильтровать спам, посмотрите и там.

Что сделано для надёжности:

- Сервер не принимает запросы с чужого сайта (проверка `Origin`).
- Повторное нажатие в течение 30 секунд (двойной тап, перезагрузка) не отправляет второе письмо.
- Если у Сабины в этот момент пропала сеть, запрос повторяется три раза, а затем сохраняется в `localStorage` и уходит при следующем открытии страницы.
- Сабине ничего не показывается про почту: ошибки отправки никак не портят момент.

### Другой почтовый сервис

Вся отправка находится в одной функции `sendForgivenNotification` в `src/lib/mailer.js`. Чтобы использовать другой сервис, поменяйте там адрес запроса и формат тела; переменные окружения и остальной код останутся прежними.

## Размещение

Проект рассчитан на Vercel (бесплатный тариф подходит): импортируйте репозиторий, добавьте переменные окружения выше и нажмите Deploy. Подойдёт и любой хостинг с Node.js (`npm run build && npm start`). Статический экспорт не подойдёт, потому что нужен серверный маршрут для почты.

Страница закрыта от поисковиков (`noindex`), так как это личное письмо.

## Структура

```
src/
  app/
    layout.js              шрифты, метаданные, viewport
    globals.css            цвета, бумага, общие стили
    page.js
    api/forgiven/route.js  серверный маршрут: принимает «Да» и отправляет письмо
  components/
    LetterExperience.js    управляет этапами: код -> конверт -> письмо -> финал
    CodeGate.js            ввод кода и кнопка «Открыть»
    EnvelopeScene.js       конверт: печать, клапан, лист выходит и разворачивается (3D на CSS)
    LetterSheet.js         лист с письмом и «рукописным» появлением текста
    ForgiveQuestion.js     «Ты меня простишь?», «Да» и убегающая «Нет»
    Finale.js              финальный экран
    Atmosphere.js          фон: свет, частицы, сердечки
    Butterflies.js         бабочки (простая симуляция полёта)
    EffectsCanvas.js       canvas для конфетти и фейерверков (движок: src/lib/effects.js)
  lib/
    content.js             все тексты и код
    runaway.js             где «Нет» может приземлиться
    mailer.js              отправка письма (только сервер)
    notify.js              отправка «Да» с повторами (браузер)
```

## Телефоны и доступность

- Поле кода и кнопки крупные, для касания (от 54 px), шрифт поля не меньше 16 px, поэтому iPhone не увеличивает страницу при фокусе.
- Горизонтальной прокрутки нет; учитываются вырезы экрана (`safe-area`) и динамическая высота экрана на iPhone (`dvh`).
- При включённой системной настройке «уменьшить движение» (`prefers-reduced-motion`): конверт открывается простым появлением письма, текст появляется сразу, нет падающих частиц и фейерверков, остаются три неподвижно-плавных бабочки и несколько медленных сердечек в финале.
