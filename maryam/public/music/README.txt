Put the background music here and name it music.mp3

    public/music/music.mp3

- Any calm, romantic track works (instrumental piano or strings is ideal). Use music you have the right to use.
- 2 to 4 minutes is plenty: the track loops.
- Keep the file under about 5 MB so the page stays fast on a phone (128 kbps mp3 is fine).
- It starts quietly (a slow fade-in) after the "Открыть письмо" button is pressed.
- The file is picked up when the site is built, so rebuild / redeploy after adding it.

If there is no music.mp3, the page plays a very quiet melody that it generates itself.
